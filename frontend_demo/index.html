Proposed implementation stack

Android and Kotlin provide the mobile companion. The proposed laptop daemon uses Python or Node.js, with REST and JSON-RPC for application interfaces. NectarLink handles the paired connection. OpenClaw coordinates MCP servers, including Playwright for browser operations and python-docx or docxtpl for reports. The security design uses scoped roles, encrypted communication, and cryptographic signatures.

    What the platform records

    The proposed audit logger records task creation, tool invocations, permission decisions, artifact hashes, approvals, rejections, timestamps, and execution outcomes. Task IDs tie the records back to the original request. The monitor exposes the live trace and controls. Tamper-evident audit storage is planned as a future enhancement.
